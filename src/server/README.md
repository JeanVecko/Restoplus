# Code serveur

Les cas d’usage, politiques d’accès et dépôts de données futurs seront regroupés ici ou dans les modules correspondants. Tout accès métier devra authentifier l’utilisateur, vérifier rôle et établissement, valider l’entrée puis accéder aux données dans une transaction tenant-aware. Aucun accès PostgreSQL n’est configuré au Jalon 1.
